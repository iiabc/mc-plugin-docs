## 连接类问题

### 玩家标签列表显示异常
**现象**  
玩家名称在标签列表无颜色/样式异常

**解决方案**  
1. 执行 `/viaversion autoteam` 禁用自动队伍功能  
2. 若使用 ColoredTags 等标签插件，需在 `config.yml` 中设置：  
   ```yaml
   auto-team: false
   ```

### 客户端提示「服务器过时」
**排查步骤**  
1. 检查代理层（BungeeCord/Velocity）是否为最新版  
2. 确认 ViaVersion 已正确加载（查看启动日志）  
3. 验证玩家连接的目标子服地址是否正确

## 功能异常类

### 使用 /reload 后出现问题
**风险说明**  
ViaVersion 与 ProtocolLib 配合时，重载可能导致：  
- 玩家被强制踢出  
- 部分功能失效  

**推荐方案**  
- 修改配置后使用 `/viaversion reload`  
- 重大更新时 **重启服务器**

### 无法使用新版本方块
**设计原则**  
ViaVersion **不提供**以下功能：  
- 高版本方块在低版本客户端的降级显示  
- 跨版本物品交互逻辑转换

## 性能类问题

### TPS 延迟异常
**可能原因**  
服务端版本 ≤1.8 时，ViaVersion 需模拟玩家状态检测机制

**优化方案**  
```yaml
# config.yml
nms-player-ticking: false
```
> 注意：关闭此选项可能导致反作弊插件误判

### 数据包错误警告
**版本对应策略**  
| 服务端版本 | 处理建议                          |
|------------|-----------------------------------|
| 1.8.x      | 检查第三方插件兼容性              |
| ≥1.9.x     | 更新至 ViaVersion 最新构建版本    |

## 代理层问题排查

### BungeeCord/Velocity 失效
**诊断流程**  
1. 单独测试纯净代理环境  
2. 检查子服版本探测状态：  
   ```bash
   /viaversion probe
   ```
3. 等待 5-10 分钟完成自动协议协商

### 防火墙配置要求
确保开放以下端口：  
- `TCP 443` (诊断报告生成)  
- `UDP 19132` (基岩版穿透)
