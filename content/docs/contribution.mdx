## 🛠️ 开发环境配置

1. **代码库克隆**  
   ```bash
   git clone https://github.com/iiabc/mc-plugin-docs.git
   cd mc-plugin-docs
   ```

2. **依赖安装**  
   ```bash
   pnpm install
   ```

3. **实时预览**  
   ```bash
   pnpm dev
   ```

## 📂 文档存放路径规范
```bash
# 免费插件文档路径
content/docs/free/<插件名>/

# 付费插件文档路径
content/docs/paid/<插件名>/

# 示例：WorldGuard 文档路径
content/docs/free/worldguard/
```

## ✍️ 中文编写规范

### 一、标点符号标准
| 符号类型       | 正确用法                      | 错误示例                      |
|----------------|------------------------------|------------------------------|
| **逗号**       | 需要Java 17，内存≥4GB         | 需要Java 17,内存>=4GB         |
| **句号**       | 配置文件位于plugins目录。     | 配置文件位于plugins目录.      |
| **括号**       | （建议使用Paper服务端）       | (建议使用Paper服务端)         |
| **引号**       | 该功能称为“协议转换”          | 该功能称为"协议转换"          |

### 二、空格使用规则
```markdown
✅ 正确示范：
- 安装 Paper 服务端
- 分配 4096M 内存
- 版本 ≥1.16 且 ≤1.20

❌ 错误示范：
- 安装Paper服务端
- 分配4096M内存
- 版本≥1.16且≤1.20
```

### 三、段落格式
```markdown
<!-- 正确段落结构 -->
ViaVersion 是跨版本兼容核心插件，主要功能是**允许低版本客户端连接高版本服务端**。

插件支持多平台部署：

1. Paper/Spigot 服务端
2. BungeeCord/Velocity 代理层
```

## 📝 Markdown 编写规范

### 一、标题层级
```markdown
# 插件名称（H1，仅用于标题）

## 安装指南（H2，核心章节）

### 注意事项（H3，子章节）

#### 兼容性说明（H4，慎用）
```

### 二、列表格式
```markdown
<!-- 有序列表 -->
1. **服务端部署**
   ```bash
   java -jar paper-1.20.4.jar

2. **插件安装**
   - 将 ViaVersion.jar 放入 `plugins` 目录
   - 重启服务端

<!-- 无序列表 -->
- 核心功能：
  - 协议版本转换
  - 数据包重映射
```

### 三、表格设计
```markdown
| 参数            | 类型    | 默认值   | 说明                     |
|-----------------|---------|----------|--------------------------|
| `max-players`   | Integer | 20       | 最大同时在线玩家数       |
| `motd`          | String  | "Welcome"| 服务器列表显示信息       |
```

### 四、配置注释规范
```yaml
# 数据库连接配置
database:
  # 数据库主机地址（支持域名或IP）
  host: localhost
  # 数据库连接端口（范围：1024-65535）
  port: 3306
```
